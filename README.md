## 🛠️ Como Executar Localmente

1.  Clone o repositório:
    ```bash
    git clone https://github.com/JoaoPauloDel/portfolio.git
    ```
2.  Instale as dependências:
    ```bash
    npm install
    ```
3.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```

## 📄 Estrutura

O projeto segue uma estrutura de componentes modularizada:

- `src/components/Header.tsx`: Navegação responsiva.
- `src/components/Hero.tsx`: Apresentação principal.
- `src/components/About.tsx`: Seção sobre mim.
- `src/components/Education.tsx`: Formação acadêmica.
- `src/components/Experience.tsx`: Experiência profissional.
- `src/components/Skills.tsx`: Lista de tecnologias.
- `src/components/Footer.tsx`: Rodapé com links.
